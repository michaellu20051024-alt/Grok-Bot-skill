# 开卷考场资料三件套

目标：考场上能最快找到「这题怎么做、公式在哪、表在哪」。实用优先，不是讲课教材（讲课式教材用 ppt 技能），排版用 latex 技能出 PDF。

## 步骤
1. 锁定范围：考试章节、不考的章节、课件底本版本；用户补发资料时先核对是否同一套。
2. 逐章清点：全部计算题型（一个不落）和各级标题知识点，记下所在部分、章、PPT 页码。
3. 出三份 PDF：
   - **题目索引**：每个题型按「一句定位（特征关键词少量红字放大）→ 一句方法 → 公式（周全但简洁，查表写「见附录 表N/图N」）→ 易错点/查表方法 → PPT 出处」排列；出处格式与知识点索引一致，放在该题型易错点之后，不堆到文末。
   - **知识点索引**：「知识点—第几部分—第几章PPT—第几页」；只高亮重要条目（约一两成）并附适用条件、临界值、判据等关键短语。
   - **附录图表**：按考场使用频次排序（常查、偶查、可能考），可多不可少。
4. 每份开头加约半页使用指南，言简意赅。
5. 分部复查，全部完成后再对着课件总检一遍；发现课件自身数据不一致要标出。
6. 按当前 bot 的交付默认交付 PDF。

## 规则
- 高亮克制：全篇飘红等于没有重点。
- 「重要」只按课件例题是否用到、老师是否强调、是否核心定律或公式来判断，不编「往年必考」。
- 数据优先用课件、权威教材附录、NIST 等，至少两处核对；对不上或只有单一来源的如实标注（如 ◇）。
- 图表文字用中文（必要符号除外）；英文原图不直接贴，重画后抽点对照例题读数，数据准确是根本。
- 版面精美实用、不花哨，字不能太小。
- 交付后如需群发，可另附一段可直接复制的使用说明。

# DSC 切线法外推起始温度

脚本：`scripts/tangent_onset.py`（Python 3，numpy / scipy / matplotlib；读 xlsx 另需 pandas + openpyxl）。

## 方法（一句话）
外推起始温度 T_e = 峰前**外推基线**（线性拟合后外延）与吸热峰**前沿拐点切线**（前沿 dDSC/dT 最大处）的交点。另报**首次偏离基线**温度（残差连续 N 点 > nσ）和峰顶温度。

## 输入
- 原始 DSC 导出文件（CSV/TXT/XLSX）。NETZSCH 导出可直接读：`#` 开头是元数据，`##` 开头那行是表头。
- 温度列、DSC 列（名称片段或 0 起列号）。
- 峰前基线区间：一段平稳、无热事件的温度段。先画全程曲线再定，不要直接套别的样品的区间。
- 吸热方向：脚本要求吸热向上。元数据里 `EXO=-1` 表示放热向下（即吸热向上），不用翻转；吸热向下的数据加 `--flip`。

## 步骤
1. 看元数据：仪器、升温速率、扫描上限、EXO 方向、点数和温度范围。写进说明。
2. 画全程曲线（可先 `--no-plot` 跑一遍看 result.json，再画），确认目标峰和峰前平稳段。
3. 运行：
   ```
   python scripts/tangent_onset.py <数据文件> --temp-col Temp --signal-col DSC \
       --baseline <LO> <HI> [--edge <LO> <HI>] [--sens-baselines "a:b,c:d"] \
       [--plot-range <LO> <HI>] --title "<样品> DSC 切线法作图过程" --outdir <输出目录>
   ```
   - `--edge` 缺省为「基线上限 → 峰顶」；前面有别的小峰干扰时手动收窄到目标峰前沿。
   - SG 平滑默认 31 点 3 阶；敏感性默认窗口 11/21/31/51 × 若干基线区间。
4. 读 `result.json`：`T_onset_extrap`（主结果）、`T_onset_raw_fit`（拐点 ±1.5 ℃ 原始点直线拟合，不平滑）、`T_first_deviation`、`T_peak`、`sens_min/sens_max`。
5. 写简短说明（MD；要 Word 时 `pandoc 说明.md -o 说明.docx`，或 python-docx），结构：结论 → 两条线各是什么 → 计算步骤和数值 → 核对（原始点拟合、敏感性）→ 限制 → 文件清单。

## 检查（交付前逐条过）
- 平滑与不平滑两种切线的 T_e 差应在零点几 ℃ 量级；差大说明拐点附近噪声大或窗口选错。
- 敏感性范围写进结论（「x–y ℃ 之间」），不只报一个数。
- 基线残差 σ 合理、基线段确实没有热事件（看图②）。
- 图④里两条切线交点、拐点、首次偏离线位置都对；图上数值与 result.json 一致。
- 拐点必须落在目标峰前沿上，而不是落在其他峰或噪声尖上（看图③）。

## 必须写明的限制
- **合金熔化**：前沿通常不是直线，切线外推的物理依据弱；测固相线更常用「首次偏离基线」温度。两个都报，并说明区别。
- 峰的归属（是否为熔化）要有证据：峰面积、是否回到基线、扫描是否覆盖到主熔化峰。证据不够时只能说「该吸热峰的外推起始温度」，不要写成「固相线」，并建议升温到更高温度复测或淬火金相验证。
- 温度校准、气氛、试样成分未核对的，照实写「未核对」。

## 不要做
- 不编数据、不补点、不“修”曲线；只用用户给的原始文件。
- 不把外推起始温度直接等同于固相线，除非有归属证据。
- 不在脚本里写死数据路径或用户信息；输出目录用用户指定的位置。
- 不只交一个数字：必须带作图过程图、敏感性和限制。

## 输出
`<outdir>/` 下：`result.json`、`sensitivity.csv`、`construction_lines.csv`（作图区间内实测值、外推基线、切线）、`切线法作图过程.png/.pdf`，加上手写的 `说明.md`（可另转 `.docx`）。
